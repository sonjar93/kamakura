# 追加仕様「源氏から北条執権へ続く世代継承型キャンペーン」― 既存コードの分析と実装計画

対象：v1.0（engine.js・types.ts・index.html）。プレイヤー操作対象の移行方式は **A方式（北条氏への完全移行）**。

## 1. いまの実装で実現できる部分
| 項目 | 現状 | 使い方 |
|---|---|---|
| 世界の状態の保持 | 全状態が一つの JSON（save/load）。日付・人物・勢力・所領・軍・朝廷・イベント・AIログをすべて含む | 操作対象を変えても世界はそのまま |
| プレイヤー操作対象 | `s.playerFaction`（勢力ID）一つで管理。AI は `playerFaction` 以外の勢力をすべて動かす | 書き換えれば、旧勢力は次の日から CPU が引き継ぐ |
| 主従 | `faction.overlord`（御家人＝従う勢力）。家臣の年貢2割、離反、寝返りの判定がある | 北条氏を源氏の御家人（overlord=yoritomo）として表せる |
| 家督継承 | v1.0 の `resolveSuccession`：安定・派閥争い・内乱・分裂 | 頼朝の死でも源氏は滅びず、将軍家として続く |
| 体制・家 | v1.0 の `faction.regime`（8指標）と `s.houses`（北条・比企） | 幕府内の影響力の土台 |
| 役職 | `person.warriorOffices`／`courtOffices`、`offices` に成立年（執権1203・連署1225・評定衆1225） | 執権・連署を役職として扱える |
| 史実イベント | 条件つきイベント（historicalEvents）、自由モードでは期限なし | 1203年の執権就任を「条件がそろえば起こる」形で書ける |
| 所領 | 本所・徴税・地頭・実効支配（v0.9） | 所領の安堵・没収の土台 |

## 2. 追加が必要な部分
1. **北条氏を独立した勢力にする**：いまは時政・義時・政子が `yoritomo` 勢力の人物。北条氏を勢力 `hojo`（overlord=yoritomo、拠点＝北条館）として分け、家（s.houses.hojo）と結ぶ。北条館は頼朝の本拠ではなくなるので、頼朝方の本拠を鎌倉へ移す扱い（史実：治承4年10月）と合わせて調整が要る。
2. **プレイヤー操作対象の移行**：`s.player = { faction, house, history: [{day, from, to, reason}] }` を追加し、`playerFaction` はその写しとして残す（既存コードとの互換）。移行できる節目（当主の死・将軍交代・家の継承・執権就任・政権交代）を判定する `transferOptions(s)` と、移行コマンド `transfer_player`。
3. **将軍家の継承**：頼家（1182年生）・実朝（1192年生）の誕生（史実イベント：条件つき）。頼朝の死後、源氏は CPU の将軍家として存続（滅亡判定から外す）。
4. **幕府内の権力闘争**：北条・比企・三浦・和田・梶原などの御家人ごとに、幕府内の影響力・将軍家との関係・北条との関係・野心・忠誠・反乱の可能性。行動（役職付与・所領安堵／没収・同盟・孤立・婚姻・将軍を通じた排除・討伐）と、御家人 CPU の対抗行動（北条への警戒・連合・将軍への接近）。
5. **執権**：役職「執権」と就任条件（幕府内の影響力が最大、将軍家との関係、政所別当、他の有力御家人の排除または合意）。1203年は「条件がそろえば起こる」史実イベント。
6. **北条一門の内部**：得宗家・庶流・連署・評定衆を人物と派閥で表す（第4優先）。

## 3. 既存仕様と衝突する部分
- **勝利条件と滅亡**：いまは「プレイヤーの家の拠点がなくなれば滅亡」「勢力の目標がそろえばクリア」。キャンペーンでは頼朝の死でも続け、執権就任後は終わらせない → 目的に「キャンペーン（北条執権）」を加え、その目的ではクリアで止めない。
- **頼朝の目標**（武家政権の樹立）：キャンペーンでは第1段階の目標として残し、達成後も続ける。
- **北条館が頼朝の本拠**：北条氏を勢力として分けると初期の本拠が変わる。頼朝の初期本拠は北条館のまま、北条氏は「頼朝の挙兵を支える家」として、鎌倉入り（史実イベント）で本拠を移す形にする。
- **人物の所属**：時政・義時が北条氏に移ると、源氏の大将の候補が減る。出陣の際に御家人の人物を大将にできる既存の仕組み（［御家人］表示）で補う。

## 4. 実装の順番（仕様の第1〜第4優先に対応）

**v1.2 で第1〜第3優先と第4優先の中心（人事・制度改革）を実装済み**（設計書17章）。北条一門の内部派閥・和田/梶原の家・将軍交代の権力闘争化は次の段階。

1. **第1優先**：北条氏の勢力化、`s.player` と移行コマンド、セーブ・ロードでの保持、移行時の世界の保持。テスト：移行の前後で日付・所領・人物・戦争が同じ。源氏は CPU が動かす。
2. **第2優先**：頼家・実朝の誕生、頼朝の死後の将軍家の継承、御家人の影響力と権力闘争（CPU 側の行動を含む）。
3. **第3優先**：執権の役職と就任条件、1203年の条件つきイベント。
4. **第4優先**：執権としての幕府運営（将軍家・御家人・所領と役職の配分・北条一門の派閥・制度改革・朝廷交渉）。終わりのないサンドボックス。
